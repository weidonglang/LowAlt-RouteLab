# LowAlt-RouteLab Diagram Inventory

This directory records v1.0.0 diagrams and generated benchmark visuals.

| 文件 | 建议内容 |
| --- | --- |
| `algorithm-comparison.png` | Dijkstra / A* / Theta* 的路径长度、风险、能耗、耗时对比 |
| `skygrid-integration.png` | LowAlt-RouteLab 输出 TimeSlot 并提交 SkyGrid 的集成链路 |
| `risk-score-comparison.png` | Benchmark risk score comparison |
| `energy-cost-comparison.png` | Benchmark energy cost comparison |
| `timeslot-comparison.png` | Benchmark TimeSlot occupancy comparison |

Generated benchmark diagrams should be derived from `algorithm-service/benchmarks/results/benchmark-summary.json`. Text alternatives are maintained in `docs/algorithm-benchmark-v1.0.0.md` and `docs/skygrid-integration-guide.md`.
